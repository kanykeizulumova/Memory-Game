# Memory Game

Игра в стиле «Memory»/«Мемори», в которой нужно находить пары одинаковых карточек. Проект выполнен на чистом HTML, CSS и JavaScript без сборки и зависимостей, поэтому его можно быстро запустить локально.

## Описание приложения

В игре пользователь открывает карточки и пытается найти совпадения. Основные возможности:

- тематический набор карточек («Властелин колец» / The Lord of the Rings);
- случайное перемешивание карточек при каждом старте (алгоритм Фишера — Йейтса);
- честный подсчёт совершённых ходов и найденных пар (0 из 8);
- блокировка взаимодействия с полем на время показа несовпавшей пары;
- возможность начать новую игру в один клик без перезагрузки страницы;
- модальное окно победы с итоговым числом ходов;
- модальное окно таблицы лидеров (топ-10 лучших результатов с сохранением в `localStorage`);
- модальные окна с закрытием по клику на затемнённый фон, кнопке «Закрыть» и клавише Escape;
- адаптивный интерфейс под разные размеры экрана;
- полная генерация DOM через JavaScript (`document.createElement`) без использования запрещённых методов.

Игровой процесс прост и понятен: нужно переворачивать по две карточки, запоминать их расположение и собирать все пары за наименьшее число ходов.

## Требования

Для запуска достаточно:

- современного браузера;
- локального веб-сервера или возможности открыть файл в браузере.

Так как приложение использует внешние изображения, рекомендуется запускать его через локальный сервер, чтобы избежать проблем с загрузкой ресурсов.

## Локальный запуск

### Вариант 1: запуск через локальный сервер

1. Откройте каталог проекта в VS Code.
2. Откройте терминал: `Terminal` → `New Terminal`.
3. Выполните команду:

```bash
python -m http.server 8000
```

Если в Windows команда `python` не сработает, попробуйте:

```bash
py -m http.server 8000
```

или

```bash
python3 -m http.server 8000
```

4. После запуска сервера откройте в браузере страницу:

```text
http://localhost:8000
```

На Windows запуск обычно выглядит так: вы открываете VS Code, запускаете терминал, вводите одну из команд выше и ждёте, пока сервер начнёт слушать порт `8000`. После этого сайт доступен локально по адресу `localhost:8000`.

### Вариант 2: открыть файл напрямую

1. Откройте папку проекта в файловом менеджере.
2. Дважды щёлкните по файлу `index.html`.

Этот способ тоже работает, но иногда браузер может вести себя менее предсказуемо с внешними ресурсами, поэтому предпочтительнее использовать локальный сервер.

## Структура проекта

- `index.html` — основная HTML-структура страницы;
- `style.css` — стили и визуальное оформление;
- `script.js` — логика игры, карточки, таймер, победа и таблица лидеров;
- `assets/` — графические ресурсы проекта.

## Команда для запуска проекта из корня

```bash
cd "путь/к/проекту"
python -m http.server 8000
```

После этого можно открыть `http://localhost:8000` и начать игру.
